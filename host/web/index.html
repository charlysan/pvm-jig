Settings

The first time auto-apply is turned on, the current EEPROM is saved as the baseline. Settings can't be changed while editing: Save or Revert first.

Editing in the panel: Save or Revert there first. Profiles copy what is in the EEPROM, and nothing is applied while editing.

“Copy monitor →” stores the values in the EEPROM now: tune with Edit and Save first. “Apply → monitor” on a card writes it to the monitor (baseline + that preset or core profile; the baseline alone on the Baseline card) and holds until the next core change. Presets are only applied by hand; a core uses the baseline plus its own profile, the menu the baseline.
